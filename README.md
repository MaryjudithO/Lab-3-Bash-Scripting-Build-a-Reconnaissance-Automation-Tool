# Lab3_Bash_Scripting_Recon_Tool_Maryjudith_Ogunaka.pdf
Lab 3 report on a Bash-based reconnaissance tool. The script takes a user-supplied target, presents a menu-driven interface via Bash case statements, and runs WhatWeb, Nmap, and DIRB against authorized targets. Includes screenshots, script code, execution results, and explanations of the Bash concepts used.
